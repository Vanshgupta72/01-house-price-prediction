# Dataset files

- `train.csv`: labeled Ames-style housing records (`SalePrice` is the target).
- `test.csv`: unlabeled records used to generate predictions.
- `submission.csv`: supplied submission template.

The supplied files contain 1,460 training rows and 1,459 test rows. Confirm the original dataset source, license, and attribution before publishing the CSVs publicly. Do not assume that the source permits redistribution solely because the files were supplied in this archive.
